# Node Workspace Access

## Overview

All nodes in the workflow now have automatic access to the workspace manager and file metadata. This enables nodes (especially LLM nodes) to:

1. **See available files** with descriptions
2. **Query workspace contents** before making decisions
3. **Include file context** in LLM prompts
4. **Register created files** for other nodes to discover

## How It Works

### Automatic Injection

When a workflow runs with workspace enabled, the workspace manager is automatically injected into all nodes:

```python
# In Workflow.run()
for node in self._nodes.values():
    node.set_workspace_manager(self.workspace_manager)
```

This happens before any node executes, so all nodes have access to the workspace manager throughout execution.

### Node Access Methods

Every node (subclass of `Node`) has these methods:

#### `workspace_manager` property
Direct access to the WorkspaceManager instance:

```python
def run(self, state):
    if self.workspace_manager:
        # Register a file
        self.workspace_manager.register_file(
            "output/results.json",
            description="Analysis results",
            file_type="result"
        )
```

#### `get_workspace_files_summary()` → str
Get LLM-friendly formatted summary of all workspace files:

```python
def run(self, state):
    # Get summary for LLM prompt
    files_summary = self.get_workspace_files_summary()

    # Build context-aware prompt
    prompt = f"""
    Available files:
    {files_summary}

    What analysis should we perform next?
    """
```

Example output:
```
Workspace Files:

input/
  - data.csv (data): Original dataset with 5 features and 1000 samples

output/
  - correlation.png (plot): Correlation heatmap of all features
  - stats.json (result): Descriptive statistics: mean, std, quartiles
```

#### `list_workspace_files(subdir=None, file_type=None)` → List[Dict]
Query files with filters:

```python
def run(self, state):
    # Get all plot files
    plots = self.list_workspace_files(file_type="plot")
    for plot in plots:
        print(f"Found plot: {plot['path']} - {plot['description']}")

    # Get all files in output directory
    output_files = self.list_workspace_files(subdir="output")

    # Get specific type in specific directory
    data_in_scratch = self.list_workspace_files(
        subdir="scratch",
        file_type="data"
    )
```

## Usage Examples

### Example 1: LLM Node Using File Context

```python
class SRAnalyzerNode(LLMNode):
    def _build_input(self, state: Dict[str, Any]) -> Dict[str, Any]:
        """Build prompt with workspace file context."""

        # Get parent's prompt
        parent_input = super()._build_input(state)

        # Add workspace file context if available
        if self.workspace_manager:
            files_summary = self.get_workspace_files_summary()

            # Add to system prompt
            context = f"""

            ## Available Workspace Files
            {files_summary}

            Consider these files when deciding next steps.
            """

            parent_input["system_prompt"] += context

        return parent_input
```

### Example 2: Node Checking for Existing Files

```python
class VisualizationNode(Node):
    def run(self, state):
        # Check if correlation plot already exists
        existing_plots = self.list_workspace_files(file_type="plot")

        has_correlation = any(
            "correlation" in f['description'].lower()
            for f in existing_plots
        )

        if has_correlation:
            logger.info("Correlation plot already exists, skipping creation")
            return state

        # Create the plot...
        self._create_correlation_plot(state)

        return state
```

### Example 3: Tool Node Registering Outputs

```python
class PythonInterpreterNode(Node):
    def run(self, state):
        # Execute Python code...
        results = self._execute_code(state['code'])

        # Register any output files created
        if self.workspace_manager:
            # Check what files were created
            output_files = Path(workspace_root) / "output"
            for file in output_files.glob("*.png"):
                # Try to infer description from filename
                desc = f"Plot generated by user code: {file.stem}"
                self.workspace_manager.register_file(
                    f"output/{file.name}",
                    description=desc,
                    file_type="plot",
                    created_by="python_interpreter"
                )

        return state
```

### Example 4: Decision Node Based on Available Files

```python
class AnalysisDecisionNode(Node):
    def run(self, state):
        """Decide what analysis to run based on available files."""

        # Get current workspace state
        result_files = self.list_workspace_files(file_type="result")
        plot_files = self.list_workspace_files(file_type="plot")

        # Make decision based on what's available
        if not result_files:
            # No analysis done yet, run exploratory analysis
            state["_next_node"] = "exploratory_analysis"
        elif not plot_files:
            # Have results but no visualizations
            state["_next_node"] = "create_visualizations"
        else:
            # Have everything, proceed to SR
            state["_next_node"] = "symbolic_regression"

        return state
```

## Integration with Existing Nodes

### For Tool Nodes (ToolSwitchNode)

Tools can access workspace manager through state:

```python
# In tool.py
import os
workspace_root = os.environ.get('WORKSPACE_ROOT')
workspace_manager = state.get('_workspace_manager')  # From state

# Register outputs
if workspace_manager:
    workspace_manager.register_file(
        "output/results.json",
        description="Tool execution results",
        file_type="result",
        created_by="tool_name"
    )
```

### For LLM Nodes (SRNode, LLMNode)

Override `_build_input` to include file context:

```python
class CustomLLMNode(LLMNode):
    def _build_input(self, state):
        # Get base input
        base_input = super()._build_input(state)

        # Add file context
        if self.workspace_manager:
            files_summary = self.get_workspace_files_summary()

            # Append to user prompt
            base_input["user_content"].append({
                "type": "text",
                "text": f"\n\n## Available Files\n{files_summary}"
            })

        return base_input
```

## Benefits

### 1. Informed Decision Making
LLM nodes can see what files exist before deciding next steps:
- "I see there's already a correlation plot, so I'll focus on other analysis"
- "No statistical analysis exists yet, should run that first"

### 2. Avoid Redundant Work
Nodes can check if work has already been done:
- Don't recreate plots that exist
- Don't re-run analysis if results are available

### 3. Context-Aware Prompts
LLM prompts include relevant file information:
- What data is available
- What analysis has been done
- What visualizations exist

### 4. Better Coordination
Multiple nodes can coordinate through shared file registry:
- Tool creates file with description
- LLM node reads description
- LLM makes informed decision

## API Reference

### Node Base Class Methods

```python
class Node:
    @property
    def workspace_manager(self) -> Optional[WorkspaceManager]:
        """Access to workspace manager."""

    def get_workspace_files_summary(self) -> Optional[str]:
        """Get formatted file summary for LLM prompts."""

    def list_workspace_files(
        self,
        subdir: Optional[str] = None,
        file_type: Optional[str] = None
    ) -> List[Dict[str, Any]]:
        """List files with metadata, optionally filtered."""
```

## Best Practices

### For Node Developers

1. **Check for workspace** before using:
   ```python
   if self.workspace_manager:
       # Use workspace features
   ```

2. **Use helper methods** instead of direct access:
   ```python
   # Good
   summary = self.get_workspace_files_summary()

   # Also OK
   summary = self.workspace_manager.get_files_summary()
   ```

3. **Include file context in LLM prompts** when relevant:
   ```python
   files = self.get_workspace_files_summary()
   prompt = f"Available files:\n{files}\n\nDecide what to do next."
   ```

4. **Filter files** to reduce noise:
   ```python
   # Only show output files to LLM
   output_files = self.list_workspace_files(subdir="output")
   ```

### For LLM Prompt Engineering

1. **Include file summaries** when LLM needs to make file-based decisions
2. **Filter by relevance** (e.g., only output files for analysis decisions)
3. **Use descriptions** to help LLM understand file purpose
4. **Consider file types** when prompting (plots vs. data vs. results)

## Migration Notes

- Existing nodes work without changes (workspace access is optional)
- Check `if self.workspace_manager` before using workspace features
- Backward compatible with non-workspace workflows
- State dictionary still contains `_workspace_manager` for compatibility
